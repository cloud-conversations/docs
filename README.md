# Cloud Conversations docs

The user guide at [docs.cloudconversations.org](https://docs.cloudconversations.org). Pages are Markdown in `docs/`. The page order is `nav` in `zensical.toml`.

## Preview

Install [uv](https://docs.astral.sh/uv/), then:

```bash
uv run zensical serve        # http://localhost:8000
```

## Publish

Push to `main` to publish to GitHub Pages.
